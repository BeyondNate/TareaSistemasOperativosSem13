## Actividad 1: Análisis de Amenazas de Seguridad[cite: 1]
* **Objetivo:** Identificar amenazas y objetivos de seguridad en un entorno organizacional.
* **Modalidad:** Grupal
* **Tiempo:** 30 minutos.

### Instrucciones:
1. Analicen el caso de una empresa que almacena información confidencial de clientes.
2. Identifiquen al menos:
   * 5 amenazas potenciales.
   * Los activos de información afectados.
   * Los objetivos de seguridad comprometidos (confidencialidad, integridad y disponibilidad).
3. Elaboren una matriz de riesgos.

### Producto esperado:
| Amenaza | Activo afectado | Impacto | Objetivo comprometido |
| :--- | :--- | :--- | :--- |
| Malware | Base de datos | Alto | Integridad |

## Actividad 7: Caso Integrador
* **Objetivo:** Integrar todos los conceptos desarrollados en la sesión.
* **Tiempo:** 45 minutos.

### Caso:
Una empresa sufrió un incidente de seguridad:
* Un empleado compartió su contraseña.
* Se produjo acceso no autorizado.
* Se alteraron registros financieros.
* No existía autenticación multifactor.

### Preguntas:
1. ¿Qué amenazas se materializaron?
2. ¿Qué objetivos de seguridad fueron afectados?
3. ¿Qué mecanismos de protección faltaban?
4. ¿Qué política de seguridad propondría?
5. ¿Qué modelo de control de acceso sería el más adecuado?

### Producto esperado:
* Informe técnico de 2 a 3 páginas.
